## Findings and actions
| ID | Sev | Area | Finding | Action |
|---|---|---|---|---|
| S1 | Medium | `api/concierge.ts` | The V rate limit counted messages only after a streamed reply finished, so a client that abandons each stream was never limited. | **Fixed:** the count now increments when the user message is stored. |
| S2 | Medium | `lib/auth.ts` | Login lockout is per IP only, and the admin emails are public in the repo. | Open. A global lock was tried, then removed after review: anyone could use it to lock the owners out. Final build: add Cloudflare Turnstile (free) or host-level rate limiting on the login, and keep the admin emails out of public config. |
| S3 | Low | `lib/runtime.ts` | `Origin: null` crashed `sameOrigin` with a 500. | **Fixed** (try/catch, returns 403). Verified locally: 403. |
| S4 | Low | `api/admin/login.ts` | A malformed body returned 500. | **Fixed:** redirects with an `invalid` error. Verified locally: 303. |
| S5 | Low | `lib/auth.ts` | A short `SESSION_SECRET` broke login after a correct password. | **Fixed:** `authConfigured()` now requires at least 32 characters, so the setup message shows instead. |

## Performance (lab, not field data)
**Method:**
- Chrome DevTools MCP on the local dev server, `mix.html`.
- Emulated phone: 412×915 at device pixel ratio 2.6, cache disabled.
- Transfer measured from Resource Timing about 7 s after load.

| | Requests | Transfer | Images |
|---|---|---|---|
| Before | 30 | 1,941 KB | 25 / 1,829 KB |
| After | 24 | 1,407 KB | 19 / 1,296 KB |

First-load transfer is 27% lower (−534 KB). Scene photos now arrive when the slab turns to that side.

**Trace:**
- Taken at 4× CPU slowdown with Fast 4G throttling.
- LCP was 4.15 s. About 2.6 s of that is render delay from the intentional opening, where gold particles form the logo before content appears.
- CLS was 0.00.
- This is a single lab run on a dev server, so it is not a Core Web Vitals claim.
- In the final build, self-host the fonts: Google Fonts CSS is render-blocking (about 318 ms of FCP).
